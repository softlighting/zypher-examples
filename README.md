# Zypher Agent Examples

Simple examples demonstrating how to use [Zypher](https://github.com/CoreSpeed/zypher) agents.

## Examples

### Calendar Agent (`/calendar`)
A calendar management agent that helps with appointments and scheduling.

### Coding Agent (`/coding`)
A coding assistant agent with file operations and error detection capabilities.

## Setup

1. Set your Anthropic API key:
   ```bash
   export ANTHROPIC_API_KEY=your_key_here
   ```

2. Run an example:
   ```bash
   cd calendar
   deno run -A main.ts
   ```

## Requirements

- [Deno](https://deno.com)
- Anthropic API key
